# STEPUP Sneaker Store

STEPUP is a responsive multi-page sneaker store website created as a team project for the Web Technologies course at Astana IT University.

## Team

- Tazhmaganbetov Rakhat — Home and Catalog pages
- Tauyekel Islam — About Us and Contact pages
- Group: SE-2508

Each team member is responsible for at least two HTML pages.

## Project Pages

- `index.html` — Home page
- `catalog.html` — Sneaker catalog
- `gallery.html` — Responsive image gallery
- `about.html` — About the store and team
- `contact.html` — Contact and order form
- `media-queries.html` — Responsive design demonstration

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- Flexbox
- CSS Grid
- Media Queries
- JavaScript for the demo order form

## Responsive Design

The website is designed for mobile, tablet and desktop devices.

Main responsive techniques:
- Bootstrap responsive grid: `col-12`, `col-md-6`, `col-lg-4`
- Responsive Bootstrap navbar with a mobile collapse button
- CSS media queries at 700px, 768px, 800px, 992px and 1000px
- Responsive typography
- Flexible product and benefit cards
- Responsive gallery grid
- Responsive contact form

## Main Features

- Responsive navigation
- Product cards
- Sneaker catalog
- Bootstrap carousel
- Responsive gallery
- Product comparison content
- Contact and order form
- Team information
- Local optimized image paths
- Accessible labels, alt text and keyboard focus styles

## Design

The project uses a dark sneaker-store theme with orange/yellow accent colors. The design focuses on readable contrast, consistent cards, clear navigation and a cohesive sneaker-store visual style.
